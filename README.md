# BrotherMeko (React Native)

Initial bare React Native scaffold for BrotherMeko with role-based navigation placeholders.

## Prerequisites

- Node.js 20+
- JDK 17 (for Android)
- Android Studio + Android SDK (for Android builds)
- Xcode + CocoaPods (for iOS builds on macOS)

## Install Dependencies

```bash
npm install
```

## Run The App

### 1) Start Metro

```bash
npm run start
```

### 2) Run on Android

```bash
npm run android
```

### 3) Run on iOS (macOS only)

```bash
npm run ios
```

## Useful Commands

```bash
npx react-native doctor
npx react-native run-android
npx react-native run-ios
```

## Project Structure

Main app code lives in `src/`:

- `src/components`
- `src/context`
- `src/navigation`
- `src/screens`
- `src/theme`
- `src/utils`
